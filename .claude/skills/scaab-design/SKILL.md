# Design system SCAAB — référence rapide

Voir `.claude/rules/design-system.md` pour la version complète.

## Règles d'or
1. Bleu primaire #003DA5 pour les CTA
2. Jaune #FFD100 = accent rare
3. Sidebar bg-scaab-blue-dark
4. Typo titres = Montserrat bold, corps = Inter, chiffres = Inter tabular-nums
5. Cards = rounded-lg shadow-sm border border-gray-200
6. Tableaux = text-sm, rows alternées, hover bleu léger

## Mobile breakpoints
- Sidebar -> drawer Sheet en < md
- Tableau -> cards en < lg
- Filtres -> modal en < md
